# Optimal_Soil_moisture
To identify the optimal soil moisture (SM) conditions for vegetation growth, we first trained an Extreme Gradient Boosting (XGBoost) model using a space–time pooled dataset that integrated dynamic climatic variables, including temperature, solar radiation, vapor pressure deficit (VPD), precipitation frequency, and SM, together with static environmental factors such as soil texture, slope, and IGBP land-cover type. Bayesian hyperparameter optimization was performed using the Optuna framework under a 5-fold spatial block cross-validation strategy, and early stopping based on validation RMSE was applied to prevent overfitting. After model training, optimal SM was identified by iteratively replacing the original SM values with a series of candidate SM levels while keeping other environmental variables unchanged. The SM value corresponding to the maximum model-predicted SIF was defined as the optimal SM condition for vegetation growth.
