# Optimal_Soil_moisture
To identify the optimal soil moisture (SM) conditions for vegetation growth, we first trained an Extreme Gradient Boosting (XGBoost) model using a space–time pooled dataset that integrated dynamic climatic variables, including temperature, solar radiation, vapor pressure deficit (VPD), precipitation frequency, and SM, together with static environmental factors such as soil texture, slope, and IGBP land-cover type.
